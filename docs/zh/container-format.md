# 容器格式

MQLT 使用小端序，当前版本为1。

| 偏移 | 字段                                   |
| ---- | -------------------------------------- |
| 0    | 4字节魔数 MQLT                         |
| 4    | uint16版本                             |
| 6    | uint16标志：位0为法线，位1为UV         |
| 8    | uint32块数量                           |
| 12   | 位置、法线、UV量化位数及保留字节       |
| 16   | float32位置原点xyz及范围               |
| 32   | float32 UV原点uv及范围                 |
| 44   | 重复的uint32载荷长度和不透明编码器字节 |

## 校验与所有权

要求至少一个块，标志已定义，保留字节为0，位数为0–30，原点有限且范围为正有限值。截断头部、载荷长度、载荷内容及尾随数据均拒绝。

容器不绑定 Draco，其他编码器可复用，但应用需传入对应解码器。decodeContainer 默认复制载荷，copyChunks: false 返回源视图，使用期间不要修改或转移源缓冲区。

## 兼容性

本次单包重构没有改变 MQLT v1。原 Tango 的块数加长度载荷容器没有 MQLT 头部，不能直接解码，需独立的旧格式迁移适配器。
