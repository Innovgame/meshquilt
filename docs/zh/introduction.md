# 认识 MeshQuilt

MeshQuilt 是面向原始几何数组的 TypeScript 网格编解码库。它将三角网格拆成较小的块，共享同一量化网格，并将编码载荷存入 MQLT 容器。

## 一个发布包，清晰的入口

| 导入             | 职责                                      |
| ---------------- | ----------------------------------------- |
| meshquilt        | 几何类型、惰性分块、共享量化与容器读写。  |
| meshquilt/draco  | 可注入 Draco 编解码器与浏览器 Worker 池。 |
| meshquilt/worker | 供应用部署的经典 Worker 文件。            |

根入口没有运行时依赖，不加载 Draco、不要求 Three.js，也不启动 Worker。Three.js 接入代码是经过测试的源码示例，不作为 npm 包发布。

## 一个网格，一套量化网格

同一个边界顶点可能被复制到相邻块。若各块采用独立包围盒，顶点可能落在不同的量化位置。MeshQuilt 基于完整输入测量一次位置和 UV 范围，让共享顶点保持一致。

## 使用前须知

- 输入为类型化数组，可用 Uint16/Uint32 索引，也可省略索引表示三角网格。
- 位置和法线是 xyz，UV 是 uv。平滑法线需在完整网格上预计算。
- 解码返回独立的原始几何块，不创建场景对象或材质。
- 文件加载、材质、变换及业务数据由应用管理。
- Draco 脚本与 WASM 由应用提供；Draco 为 Apache-2.0，MeshQuilt 为 MIT。
- 完整输出仍占用与模型大小相关的内存。官网三维预览不是性能基准。
