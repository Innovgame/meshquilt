# 量化与接缝

每个块都有自己使用的顶点副本。若各块按自己的包围盒量化，同一边界顶点可能落在不同位置，产生裂缝。

## 共享范围

位置 origin 是完整网格的最小角点，range 是最大轴跨度。UV 同样使用完整输入范围。每个块的 Draco 编码器用相同范围调用 SetAttributeExplicitQuantization。

范围先规范化到 float32，让编码器和容器保存的元数据一致。显式位置/UV 原点分别为3/2分量，范围须为正有限 float32，且覆盖输入值。

## 法线与默认值

法线使用仅由位数决定的 Draco 八面体网格；相同单位法线在不同块保持一致。默认位置14位、法线8位、UV10位，0表示禁用对应量化。

平滑法线必须在完整网格上计算，再分块。块内重算法线会产生硬边。解码后各块保持独立，合并会重新引入大缓冲分配。
